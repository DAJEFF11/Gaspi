# Gaspi 0.1.0 · vista previa

Primera versión para Windows x64 y Android: biblioteca local, MP3/FLAC y otros formatos, carátulas, búsqueda, álbumes y artistas, favoritos, playlists, cola, letras LRC/TXT, temas claro/negro mate y fantasmita animado.

## Archivos

- **Gaspi-Setup-windows-x64.exe**: instalador de Windows. Incluye EXE, DLL y datos de la aplicación.
- **Gaspi-Windows-portable.zip**: extrae toda la carpeta y abre `gaspi.exe`.
- **Gaspi-Android.apk**: instalación manual en Android.
- **SHA256SUMS.txt**: comprobaciones de integridad de las descargas.

El instalador Windows no tiene firma Authenticode. El APK de esta vista previa usa firma de depuración para uso personal. Las futuras compilaciones pueden requerir desinstalar la anterior si cambia la clave de firma; desinstalar elimina los datos privados de Gaspi.

La música permanece local. En Windows se usan los archivos originales; Android conserva una copia privada. Aún no incluye servicio Android de reproducción en segundo plano ni controles de pantalla bloqueada. Las compilaciones pasan análisis y pruebas automatizadas; no equivalen a una prueba de reproducción en cada dispositivo.
